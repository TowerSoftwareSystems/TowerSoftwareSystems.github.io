# Security

## Reporting a vulnerability

To report a security issue in this repository or the website it publishes, use GitHub's private vulnerability reporting: open this repository's **Security** tab and choose **Report a vulnerability**. Please do not open a public issue or pull request about it.

A report starts a private conversation on GitHub between you and the repository's maintainers.

## Scope

This covers this repository and the Tower Software Systems website built from it: static HTML and one stylesheet served by GitHub Pages, with no scripts, forms, accounts or cookies. It does not cover GitHub Pages itself, which belongs with GitHub, or Tower WMS, which has its own site at www.towerwms.com.
